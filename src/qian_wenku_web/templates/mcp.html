什么是 MCP？

MCP（Model Context Protocol）是让 AI 助手（如 Claude）直接访问外部资料的标准协议。 本站提供一个 MCP 服务器，让 AI 助手可以检索文库条目、阅读全文、按年份和来源浏览—— 相当于把整个文库的检索能力接入 AI 对话。

可用的工具
  • search — 全文检索，支持按年份范围、内容类型（年谱/文集/书信）、来源卷册筛选
  • get_entry — 按条目 ID 获取完整文本、日期、来源卷册，及前后条目导航
  • list_sources — 列出全部来源卷册（含条目数与时间范围），供检索时按来源过滤
接入方式

MCP 服务器是一个独立的小程序，在您的电脑上运行， 通过 HTTPS 访问 wenku.qianxuesen.org 的 JSON API。 认证使用本站相同的访问口令（请向编者索取）。

使用前请先安装 Python 3.10+ 与本仓库代码，然后： 

pip install -e '.[mcp]'
WENKU_BETA_PASSPHRASE=您的口令 qian-wenku-mcp
在 Claude Desktop 中使用

在 Claude Desktop 的配置文件 claude_desktop_config.json 中添加： 

{
  "mcpServers": {
    "qian-wenku": {
      "command": "qian-wenku-mcp",
      "env": {
        "WENKU_BETA_PASSPHRASE": "您的口令"
      }
    }
  }
}

保存后重启 Claude Desktop，在对话中即可让 Claude 直接检索文库。 例如："帮我找出钱学森在 1956 年写给郭永怀的所有信件"。

适用场景与限制

适合：让 AI 帮您跨年份、跨来源做主题性检索与综述，快速定位某段历史的全部相关条目。

请注意：MCP 不会绕过本站现有的访问控制；访问口令与网页端共用。 AI 助手的输出可能包含错误或对原文的转述偏差，引用前请回到条目页核对扫描页原文。
