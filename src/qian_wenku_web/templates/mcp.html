什么是 MCP？

MCP（Model Context Protocol）是让 AI 助手直接访问外部资料的标准协议。 本站托管了一个 MCP 服务，让 AI 助手可以直接检索文库条目、阅读全文、按年份和来源浏览—— 相当于把整个文库的检索能力接入 AI 对话。

您无需在自己电脑上安装任何软件：只需把下方的链接粘贴进您的 AI 聊天框，AI 会替您完成配置。

可用的工具
  • search — 全文检索，支持按年份范围、内容类型（年谱/文集/书信）、来源卷册筛选
  • get_entry — 按条目 ID 获取完整文本、日期、来源卷册，及前后条目导航
  • list_sources — 列出全部来源卷册（含条目数与时间范围），供检索时按来源过滤
一键接入（推荐）

复制下方链接，把它粘贴到您的 AI 聊天里（OpenCode、Claude Code、Claude Desktop 等）， 并说明"帮我安装这个 MCP"。AI 会自动编辑配置文件。

AI 会询问您的MCP 令牌（登录后可在账户页面创建）。

手动配置（高级）

如果您不想用 AI 自动配置，也可以手动把以下内容加入客户端配置。

编辑 ~/.config/opencode/opencode.jsonc（若不存在则用 opencode.json），在 mcp 部分加入：

"qian-wenku": {
  "type": "remote",
  "url": "https://wenku.qianxuesen.org/mcp/rpc",
  "headers": {
    "Authorization": "Bearer YOUR_MCP_TOKEN"
  }
}

然后重启 OpenCode。

在项目目录里运行：

claude mcp add --transport http qian-wenku \
  https://wenku.qianxuesen.org/mcp/rpc \
  --header "Authorization: Bearer YOUR_MCP_TOKEN"

默认只对当前项目生效；如需全局，加 --scope user。

编辑 claude_desktop_config.json（macOS: ~/Library/Application Support/Claude/；Windows: %APPDATA%\Claude\），在 mcpServers 内加入：

"qian-wenku": {
  "type": "http",
  "url": "https://wenku.qianxuesen.org/mcp/rpc",
  "headers": {
    "Authorization": "Bearer YOUR_MCP_TOKEN"
  }
}

保存并完全退出（重启）Claude Desktop。

编辑 ~/.codex/config.toml（Codex CLI、IDE 扩展与 ChatGPT 桌面端共用此配置），加入：

[mcp_servers.qian-wenku]
url = "https://wenku.qianxuesen.org/mcp/rpc"
bearer_token_env_var = "WENKU_MCP_TOKEN"

然后在 shell 配置（如 ~/.zshrc）中设置令牌：

export WENKU_MCP_TOKEN="YOUR_MCP_TOKEN"

重启 Codex 后，在 TUI 中输入 /mcp 确认连接。

服务信息
  • MCP endpoint URL: https://wenku.qianxuesen.org/mcp/rpc
  • 请求头: Authorization: Bearer 您的 MCP 令牌
  • 登录后可在账户页面创建和撤销 MCP 令牌；不要分享给他人。
适用场景与限制

适合：让 AI 帮您跨年份、跨来源做主题性检索与综述，快速定位某段历史的全部相关条目。

请注意：MCP 令牌与网页邮件登录相互独立，可按客户端单独撤销。 AI 助手的输出可能包含错误或对原文的转述偏差，引用前请回到条目页核对扫描页原文。
