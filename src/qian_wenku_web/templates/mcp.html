什么是 MCP？

MCP（Model Context Protocol）是让 AI 助手直接访问外部资料的标准协议。 本站托管了一个 MCP 服务，让 AI 助手可以直接检索文库条目、阅读全文、按年份和来源浏览—— 相当于把整个文库的检索能力接入 AI 对话。

您无需在自己电脑上安装任何软件，只要把下面的命令粘贴进终端运行一次，即可永久接入您的 AI 助手。

可用的工具
  • search — 全文检索，支持按年份范围、内容类型（年谱/文集/书信）、来源卷册筛选
  • get_entry — 按条目 ID 获取完整文本、日期、来源卷册，及前后条目导航
  • list_sources — 列出全部来源卷册（含条目数与时间范围），供检索时按来源过滤
快速接入
{% if beta_auth_enabled %}

选择你使用的 AI 助手，复制下方命令并粘贴到终端运行即可。命令中已为您填好访问口令。

把本站加入 ~/.config/opencode/opencode.json（若文件不存在会自动创建）：

python3 -c "
import json, pathlib
p = pathlib.Path.home()/'.config/opencode/opencode.json'
p.parent.mkdir(parents=True, exist_ok=True)
cfg = json.loads(p.read_text()) if p.exists() else {}
cfg.setdefault('mcp', {})['qian-wenku'] = {
  'type': 'remote',
  'url': 'https://wenku.qianxuesen.org/mcp/rpc',
  'headers': {'Authorization': 'Bearer YOUR_TOKEN'}
}
p.write_text(json.dumps(cfg, indent=2, ensure_ascii=False) + '\n')
print('wrote', p)
"

运行完成后重启 OpenCode，本会话即可使用 mcp_qian-wenku_* 工具。

把本站加入 ~/.claude.json（当前目录的作用域）：

claude mcp add --transport http qian-wenku \
  https://wenku.qianxuesen.org/mcp/rpc \
  --header "Authorization: Bearer YOUR_TOKEN"

运行后，当前项目里就能用 qian-wenku 工具。

打开 Claude Desktop 配置文件 claude_desktop_config.json，插入以下内容（macOS: ~/Library/Application Support/Claude/；Windows: %APPDATA%\Claude\）：

"qian-wenku": {
  "type": "http",
  "url": "https://wenku.qianxuesen.org/mcp/rpc",
  "headers": {
    "Authorization": "Bearer YOUR_TOKEN"
  }
}

保存并完全退出（重启）Claude Desktop 后生效。

服务地址
  • MCP endpoint URL: https://wenku.qianxuesen.org/mcp/rpc
  • 请求头: Authorization: Bearer 您的访问口令
  • 访问口令即本网站登录口令，由编者分发；不要分享给他人。
适用场景与限制

适合：让 AI 帮您跨年份、跨来源做主题性检索与综述，快速定位某段历史的全部相关条目。

请注意：MCP 与网页端共用同一个访问口令，不会绕过现有访问控制。 AI 助手的输出可能包含错误或对原文的转述偏差，引用前请回到条目页核对扫描页原文。
