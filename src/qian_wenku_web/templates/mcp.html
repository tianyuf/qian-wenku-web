什么是 MCP？

MCP（Model Context Protocol）是让 AI 助手（如 Claude）直接访问外部资料的标准协议。 本站托管了一个 MCP 服务，让 AI 助手可以直接检索文库条目、阅读全文、按年份和来源浏览—— 相当于把整个文库的检索能力接入 AI 对话。

您无需在自己电脑上安装任何软件，只要支持 MCP 的 AI 客户端 （如 Claude Desktop），把本站的服务地址和访问口令填进去即可。

可用的工具
  • search — 全文检索，支持按年份范围、内容类型（年谱/文集/书信）、来源卷册筛选
  • get_entry — 按条目 ID 获取完整文本、日期、来源卷册，及前后条目导航
  • list_sources — 列出全部来源卷册（含条目数与时间范围），供检索时按来源过滤
接入方式

MCP 服务的地址与令牌（bearer token）如下所示。 访问口令就是本站账号口令，请向 mail@qianxuesen.org 索取。

  • 服务地址（MCP endpoint URL）: https://wenku.qianxuesen.org/mcp/rpc
  • 请求头： Authorization: Bearer 您的口令
在 Claude Desktop 中使用

打开 Claude Desktop 的配置文件 claude_desktop_config.json，加入： 

{
  "mcpServers": {
    "qian-wenku": {
      "type": "http",
      "url": "https://wenku.qianxuesen.org/mcp/rpc",
      "headers": {
        "Authorization": "Bearer 您的口令"
      }
    }
  }
}

保存并重启 Claude Desktop 后，可以直接对 Claude 说： "帮我找出钱学森在 1956 年写给郭永怀的所有信件。"

适用场景与限制

适合：让 AI 帮您跨年份、跨来源做主题性检索与综述，快速定位某段历史的全部相关条目。

请注意：MCP 与网页端共用同一个访问口令，不会绕过现有访问控制。 AI 助手的输出可能包含错误或对原文的转述偏差，引用前请回到条目页核对扫描页原文。
